# Agrégateur de flux RSS - Le Monde

## 📋 Description du projet

Application web de gestion et consultation de flux RSS du journal Le Monde, développée en PHP avec stockage en fichiers CSV.

## 🎯 Objectifs

Créer un agrégateur permettant aux utilisateurs de :
- S'inscrire en sélectionnant leurs centres d'intérêt
- Consulter les flux RSS correspondant à leurs abonnements
- Gérer leurs préférences et abonnements
- Récupérer leur mot de passe en cas d'oubli

## ✨ Fonctionnalités principales

### Inscription utilisateur
- Formulaire d'inscription avec sélection des centres d'intérêt
- Envoi d'un email de validation
- Activation du compte via lien de confirmation

### Authentification
- Connexion avec identifiant et mot de passe
- Déconnexion sécurisée
- Récupération de mot de passe par email

### Gestion des flux RSS
- Consultation des flux RSS selon les abonnements
- Modification des centres d'intérêt et abonnements
- Affichage personnalisé des articles

## 🗂️ Architecture technique

- **Langage** : PHP
- **Stockage** : Fichiers CSV
- **Gestion emails** : Système d'envoi pour validation et récupération
